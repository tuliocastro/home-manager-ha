# Changelog

## 0.3.146

### Improved
- Improved the internal organization of document lists and processing status views to support future dashboard updates, while preserving existing actions and navigation.

## 0.3.145

### Improved
- Shopping list quantity controls now increase or decrease quantities by one per tap.
- Shopping item entry is now free text without a dropdown of saved Staples.
- Quick-add Staples are ordered by how often the household has bought them.

## 0.3.144

### Improved
- To Do task archiving now uses the shared cancel-first confirmation dialog.
- Cancelling archive leaves the task active; confirming preserves its existing history.
- Document details now show the cached Google Drive folder path for the saved file location.
- The folder path is display-only and does not change Drive files or document metadata.

## 0.3.143

### Improved
- Document details now show the cached Google Drive folder path for the saved file location.
- The folder path is display-only and does not change Drive files or document metadata.

## 0.3.142

### Improved
- The To Do editor now protects unsaved task changes and supports accessible keyboard dismissal.
- Dashboard Refresh now reloads tasks when the To Do view is active.

## 0.3.140

### Added
- Home Assistant updates now include a version-specific changelog with user-facing improvements and fixes.

## 0.3.139

- Release notes were not recorded for earlier versions. Future updates will list their user-facing changes here.
